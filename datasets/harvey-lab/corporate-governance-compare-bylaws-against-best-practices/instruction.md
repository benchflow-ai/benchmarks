# Compare Corporate Bylaws Against Best Practice Governance Guidelines and Produce Deviation Report

Compare the restated bylaws against the governance best practice guidelines and produce a detailed, board-ready report of all deviations and alignments. Output: `governance-deviation-report.docx`.

## Expected Deliverables

- `governance-deviation-report.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
