# Credit Agreement vs. Commitment Letter Deviation Report for Leveraged Buyout Financing

Compare the draft credit agreement against the commitment letter, term sheet, and no-flex confirmation, and flag all deviations in a structured report with an executive summary memo.

Output: `deviation-report.xlsx` and `executive-summary.docx`.

## Expected Deliverables

- `deviation-report.xlsx`
- `executive-summary.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
