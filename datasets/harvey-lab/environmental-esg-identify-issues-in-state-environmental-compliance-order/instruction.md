# Identify Issues in State Environmental Compliance Order — Issue Memorandum

Review the attached compliance order/NOV against the supporting permits, audit, inspection report, DMRs, manifests, and other facility records; produce a defense memorandum identifying all deficiencies and recommended responses. Output: `conov-issue-memorandum.docx`.

## Expected Deliverables

- `conov-issue-memorandum.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
