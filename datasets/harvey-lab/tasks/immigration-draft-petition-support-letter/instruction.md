# Draft Expert Opinion Letter for EB-1A Extraordinary Ability Petition

Draft an expert opinion letter supporting an EB-1A petition and a separate memo flagging cross-document discrepancies or unverifiable claims, using the attached source documents. Output: `expert-opinion-letter.docx` and `issues-memo.docx`.

## Expected Deliverables

- `expert-opinion-letter.docx`
- `issues-memo.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
