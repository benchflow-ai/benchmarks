# Draft Qualified Domestic Relations Orders (QDROs) for 401(k) and Defined Benefit Pension Plans

Draft two QDROs and a cover memo based on the attached settlement agreement, decree, plan procedures, statements, and correspondence. Output: `qdro-401k-plan.docx`, `qdro-pension-plan.docx`, and `qdro-issues-memorandum.docx`.

## Expected Deliverables

- `qdro-401k-plan.docx`
- `qdro-pension-plan.docx`
- `qdro-issues-memorandum.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
