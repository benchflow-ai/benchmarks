# Draft Commercial Real Estate Construction Loan Agreement for Mixed-Use Development

Draft a construction-to-mini-perm loan agreement based on the attached term sheet, credit memo, appraisal, title commitment, environmental report, org chart, and draw schedule; also prepare a cover memo flagging material issues and inconsistencies across the source documents with recommended resolutions. Output: `loan-agreement-draft.docx` and `cover-memorandum.docx`.

## Expected Deliverables

- `loan-agreement-draft.docx`
- `cover-memorandum.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
