# Draft Bilateral NDA from Deal Parameters for Potential Strategic Acquisition

Draft a bilateral NDA for the attached potential acquisition and prepare a cover memo explaining key drafting decisions and open issues. Output: `bilateral-nda-draft.docx` and `cover-memorandum.docx`.

## Expected Deliverables

- `bilateral-nda-draft.docx`
- `cover-memorandum.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
