Draft a cash collateral stipulation and an accompanying counsel memorandum identifying issues in the lender's proposed terms, using the attached source documents. Output: `cash-collateral-stipulation.docx` and `counsel-memorandum.docx`.

## Expected Deliverables

- `cash-collateral-stipulation.docx`
- `counsel-memorandum.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
