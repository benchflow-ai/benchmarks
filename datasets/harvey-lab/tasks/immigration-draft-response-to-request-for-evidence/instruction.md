# Draft Response to USCIS Request for Evidence for H-1B Specialty Occupation Petition

Draft an RFE response letter and internal strategy memo for the attached H-1B petition materials and RFE notice.

Output: `rfe-response-letter.docx` and `strategic-memo.docx`.

## Expected Deliverables

- `rfe-response-letter.docx`
- `strategic-memo.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
