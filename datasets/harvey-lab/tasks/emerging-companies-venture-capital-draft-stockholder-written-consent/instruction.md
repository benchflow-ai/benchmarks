# Draft Stockholder Written Consent for Series B Corporate Actions Authorization

Draft a stockholder written consent and accompanying drafting memo based on the attached charter, board resolutions, term sheet, IRA, cap table, proposed certificate, equity plan summary, and investor counsel email.

Output: `stockholder-written-consent.docx` and `drafting-memorandum.docx`.

## Expected Deliverables

- `stockholder-written-consent.docx`
- `drafting-memorandum.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
