# Draft External Privacy Notice for Digital Health Platform

Draft an external privacy notice and a companion compliance memorandum based on the attached data processing inventory, internal emails, existing notice, vendor agreements, retention memo, UK expansion checklist, and product specs. Output: `privacy-notice.docx` and `compliance-memorandum.docx`.

## Expected Deliverables

- `privacy-notice.docx`
- `compliance-memorandum.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
