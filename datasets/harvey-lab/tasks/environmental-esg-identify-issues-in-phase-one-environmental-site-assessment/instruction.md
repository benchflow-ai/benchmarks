# Identify Issues in Phase One Environmental Site Assessment for Industrial Acquisition

Review the Phase I ESA and supporting environmental documents for the proposed acquisition and prepare an issues memo with severity ratings. Output: `environmental-issues-memo.docx`.

## Expected Deliverables

- `environmental-issues-memo.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
