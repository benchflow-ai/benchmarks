# Draft Engineering Procurement Construction Contract (EPC) for Utility-Scale Solar Project

Draft an owner-oriented EPC contract for a utility-scale solar project using the attached term sheet, lender requirements, bid proposal, tax incentive memo, schedule, and direct agreement terms; separately prepare an issues memo flagging cross-document conflicts, gaps, and risks. Output: `epc-contract.docx` and `issues-memo.docx`.

## Expected Deliverables

- `epc-contract.docx`
- `issues-memo.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
