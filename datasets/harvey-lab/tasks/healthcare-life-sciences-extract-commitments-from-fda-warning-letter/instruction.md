# Extract Commitments and Obligations from FDA Warning Letter into Compliance Obligation Register

Extract all commitments, corrective actions, and regulatory obligations from the attached FDA and company documents and compile a compliance obligation register with a summary and risk assessment tab.

Output: `compliance-obligation-register.xlsx`

## Expected Deliverables

- `compliance-obligation-register.xlsx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
