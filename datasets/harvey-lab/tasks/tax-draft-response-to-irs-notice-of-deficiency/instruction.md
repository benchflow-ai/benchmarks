# Draft Response to IRS Notice of Deficiency for Partnership Tax Adjustments

Draft a formal response letter to the attached IRS Notice of Deficiency, challenging all proposed adjustments with supporting legal authority and requesting an Appeals conference. Output: `irs-deficiency-response-letter.docx`.

## Expected Deliverables

- `irs-deficiency-response-letter.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
