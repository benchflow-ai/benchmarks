# Draft Markup of IRS Form 906 Closing Agreement with Explanatory Comment Letter

Review the proposed closing agreement against the supporting documents; produce a redline with bracketed comments and a formal response letter to the Appeals Officer. Output: `closing-agreement-redline.docx` and `comment-letter-to-irs.docx`.

## Expected Deliverables

- `closing-agreement-redline.docx`
- `comment-letter-to-irs.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
