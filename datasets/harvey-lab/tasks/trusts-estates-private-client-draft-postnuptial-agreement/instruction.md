# Draft Postnuptial Agreement for Kowalski Couple Under Illinois Law

Draft a postnuptial agreement based on the attached intake memo, existing prenup, financial disclosures, negotiation emails, counsel letters, and business appraisal, with a cover memo flagging issues and drafting decisions. Output: `postnuptial-agreement.docx` and `cover-memo.docx`.

## Expected Deliverables

- `postnuptial-agreement.docx`
- `cover-memo.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
