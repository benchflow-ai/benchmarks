# Draft Private Equity Fund Subscription Agreement for Public Pension Plan Investor

Draft a subscription agreement for a public pension plan's commitment to the attached fund, and prepare an issues memo flagging cross-document inconsistencies needing resolution before execution. Output: `subscription-agreement-omers-or.docx` and `issues-memorandum.docx`.

## Expected Deliverables

- `subscription-agreement-omers-or.docx`
- `issues-memorandum.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
