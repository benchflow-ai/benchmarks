# Compare USCIS Filing Receipt Against Original Petition Submission — Discrepancy Report

Compare the USCIS receipt notice against the petition submission documents and flag all discrepancies, internal inconsistencies, and errors in a categorized report. Output: `discrepancy-report.docx`.

## Expected Deliverables

- `discrepancy-report.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
