# Federal Complaint Drafting — Breach of Contract and Fiduciary Duty

Draft a federal complaint with all viable claims, an exhibit list, and a strategic cover memo based on the attached matter file.

Output: `federal-complaint.docx`, `exhibit-list.docx`, and `cover-memo.docx`.

## Expected Deliverables

- `federal-complaint.docx`
- `exhibit-list.docx`
- `cover-memo.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
