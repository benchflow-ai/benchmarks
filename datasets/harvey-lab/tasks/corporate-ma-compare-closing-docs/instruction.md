# PE Acquisition Closing Deliverable Compliance Check — Verify Closing Documents Against SPA Requirements

Verify the closing deliverables against the SPA's closing requirements and produce a report noting any missing, incomplete, or non-conforming items with recommended actions.

Output: `closing-deliverable-verification-report.docx`

## Expected Deliverables

- `closing-deliverable-verification-report.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
