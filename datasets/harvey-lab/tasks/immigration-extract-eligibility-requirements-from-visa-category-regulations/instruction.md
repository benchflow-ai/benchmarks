# Extract Eligibility Requirements from Visa Category Regulations into Structured Eligibility Matrix

Extract visa eligibility requirements from the six attached documents for all ten categories and compile a structured matrix; then flag all cross-document inconsistencies, errors, and omissions in a separate report. Output: `eligibility-matrix.docx` and `discrepancy-report.docx`.

## Expected Deliverables

- `eligibility-matrix.docx`
- `discrepancy-report.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
