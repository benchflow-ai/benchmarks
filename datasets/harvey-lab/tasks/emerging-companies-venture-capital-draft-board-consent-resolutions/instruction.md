# Draft Written Consent of the Board of Directors for Series B Preferred Stock Financing

Draft a board written consent authorizing the Series B preferred stock financing, matching the style of the prior consent; flag any cross-document discrepancies in a cover memo. Output: `series-b-board-consent.docx` and `drafting-cover-memo.docx`.

## Expected Deliverables

- `series-b-board-consent.docx`
- `drafting-cover-memo.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
