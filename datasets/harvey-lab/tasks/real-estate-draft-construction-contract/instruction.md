Draft a construction contract from the attached source documents using a modified AIA A101/A201 single-document structure, and flag cross-document inconsistencies in a separate memo. Output: `construction-contract-pinnacle-ironclad.docx` and `drafting-issues-memo.docx`.

## Expected Deliverables

- `construction-contract-pinnacle-ironclad.docx`
- `drafting-issues-memo.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
