# Draft Party Cost Submissions for ICC International Commercial Arbitration

Draft a cost submission to the ICC Tribunal seeking recovery of claimant's costs based on the attached billing records, award excerpt, and procedural orders. Output: `claimant-cost-submission.docx`.

## Expected Deliverables

- `claimant-cost-submission.docx`

## Workspace Layout

- Input documents are in `documents/` (read-only).
- Write deliverables to the current working directory (`/app/`).
- Use the `read` tool for .docx, .xlsx, .pptx, .pdf files.
